# MUSLIM DNS DOMAINE

Independent multi-extension domain registry project.

## Initial modules
- Registry engine
- Extension catalogue
- Domain registration prototype
- REST API
- Automated tests
- Linux AMD64 and ARMv7 builds

## API
- GET /health
- GET /v1/extensions

IMPORTANT:
The initial registry is a development prototype.
It does not yet provide public root DNS delegation,
official TLD registration, or globally resolvable domains.
